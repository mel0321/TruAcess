# TruAcess Mobile

Aplicativo em Expo/React Native. Para iniciar:

```bash
npm install
npx expo start
```

Inicie também a API do projeto na porta `3000`. O app usa `10.0.2.2` no emulador Android e `localhost` no simulador iOS. Para um aparelho físico, defina `EXPO_PUBLIC_API_URL` com o endereço LAN do computador, por exemplo `http://192.168.1.10:3000/api`.
